# 流星三维监测网 · Meteor Triangulation Network

多站楼顶相机流星自动检测、天文标定、两站/三站视线交会三维轨迹与流星群辐射点分析系统。
纯 TypeScript 实现，视频处理全部在 **Web Worker** 中完成，星图与三维交会几何绘制在 **Canvas** 上。

## 功能页面

| 页面 | 路由 | 内容 |
| --- | --- | --- |
| 站点管理 | `#/stations` | 三站真实坐标网（兴隆/房山/青龙）、相机 FOV、按真实亮星表自动天文标定、RMS 残差、新增站点 |
| 每晚检测 | `#/nights` | 夜晚列表、Worker 合成检测演示、**上传真实视频抽帧检测**、确认流星卡片、飞机/卫星/飞虫/闪电排除统计 |
| 流星详情 | `#/meteor/:id` | 逐帧像素→RA/Dec、Canvas 星图、反推辐射点 vs 群公布辐射点、两/三视图交会几何、高度/速度与参考解对比、逐帧赤道坐标表 |
| 流星群统计 | `#/showers` | 英仙/双子/狮子/猎户/象限仪等群的夜聚合辐射点、2° 验收条、平均速度/高度、辐射点天区图 |
| 精度验证 | `#/validation` | 完整验收报告（由 `npm run validate` 生成） |

## 快速开始

```bash
npm install
npm run dev        # http://127.0.0.1:5180
npm run build      # tsc 类型检查 + vite 生产打包
```

重新生成内置演示数据集（5 个流星群之夜、缩略图、参考解）：

```bash
npm run seed
```

## 精度验收（合成真值多站视频）

按 **象限仪、英仙、猎户、狮子、双子** 5 个流星群的公布辐射点/速度，
用真实 Hipparcos 亮星（mag ≤ 5.0，1627 颗）+ WGS84/GMST/gnomonic 投影，
合成带完整三维真值的多站视频，并运行与浏览器完全相同的检测/标定/交会代码。

```bash
npm run validate          # 完整：2 随机种子 × 5 群 × 7 颗 + 3 站时误报测试
npx tsx scripts/validate.ts --quick   # 快速冒烟
```

最近一次完整结果（`src/seed/validation-report.json`）：

- 事件召回率 **94.3%**（66/70，≥90% 达标）；站级观测召回 91.3%
- 误报 **1 个 / 1 站时**（≤3/h 达标；加入静止热点抑制后的快速复验为 0/h）
- 夜聚合辐射点与公布值平均偏差 **0.36°**、最大 **1.04°**（≤2° 达标）
- 进入高度相对真值平均误差 2.07%、最大 4.42%；速度平均 0.22%、最大 2.30%
- **66/66 颗**高度与速度误差均 ≤5%

> “与公开流星网络同一颗流星结果对比”在本环境中以合成真值承担
> GMN/CAMS/EDMOND 联合参考解的角色（UI 中明确标注为“合成同轨参考解”），
> 因为验收要求的带真值多站视频本身需要按流星群自行合成。

## 处理链路

```
视频帧 GrayFrame
  └─ MovingBackground   亮星质心匹配估计星场平移 + 双线性重采样差分 + EMA 背景更新（前景禁更新）
      └─ 稳健阈值        median/MAD 估计噪声 σ，阈值 max(18, 5.4σ)
          └─ 连通域+PCA  面积/包围盒/二阶矩 → 长度/宽度/偏心率
              └─ 轨迹关联 速度预测波门 + 稳健直线拟合去野点
                  └─ 分类  直线/速度/时长/虚焦肥圆斑/闪烁缺帧/全局闪电
                      └─ PlateSolution  星表匹配 + 6 系数 affine 切平面底片模型
                          └─ pixel→ENU ray→ECEF→ECI→RA/Dec
                              └─ 联合最小二乘  X(t)=p0+v·(t−t0)，[u]×(X−S)=0
                                  └─ WGS84 高度 / |v| 速度 / −v 惯性方向→辐射点
                                      └─ 跨站分组 + 流星群归属 + 辐射点矢量聚合
```

## 目录


## 说明

- 上传真实视频时，主线程按 ≤15 fps 抽帧、缩放到宽 640，RGBA 缓冲 Transferable 传入 Worker；
  单站上传只产出像素轨迹与 RA/Dec，多站分别处理同一夜晚后才会交会。
- 合成器刻意加入传感器高斯噪声、飞机双闪/红信标、缓慢卫星、大虚焦蛇形飞虫、
  全域闪电与亮星，避免检测器只在干净画面上有效。
